# ParrelSync 多人游戏测试指南

## 什么是ParrelSync？
ParrelSync是一个Unity插件，允许你同时运行多个Unity实例来测试多人游戏，无需每次都打包。

## 使用方法

### 1. 启动服务器
```bash
cd server
go run frame_sync_server.go
```

### 2. 在Unity中使用ParrelSync

1. **打开Unity项目**
2. **在菜单栏找到 "ParrelSync"**
3. **点击 "Clones Manager"**
4. **点击 "Create New Clone"** 创建克隆实例
5. **在克隆实例中点击 "Open In New Editor"** 打开新的Unity实例

### 3. 测试流程

1. **主实例**：创建房间
2. **克隆实例**：加入房间
3. **两个实例可以同时运行，无需打包**

## 网络连接

- **所有客户端都连接到同一个端口：8080**
- **这是真实网络环境的正确做法**
- **服务器通过TCP连接自动区分不同客户端**
- **ParrelSync克隆实例会在日志中显示唯一标识**

## 真实网络部署

当部署到真实网络环境时：

### 服务器端
```bash
# 在服务器上运行
go run frame_sync_server.go
# 服务器监听 0.0.0.0:8080
```

### 客户端
```csharp
// 修改连接地址为服务器IP
tcpClient = new TcpClient("your-server-ip", 8080);
```

### 端口配置
- **开发环境**：localhost:8080
- **生产环境**：your-server-ip:8080
- **所有客户端使用相同端口**

## 注意事项

1. **所有实例连接到同一个端口8080**
2. **服务器通过TCP连接自动管理多个客户端**
3. **ParrelSync克隆实例会在日志中显示标识**
4. **真实网络环境中所有客户端连接同一服务器**

- ✅ 实时调试，可以设置断点
- ✅ 支持多个客户端同时测试
- ✅ 保持开发环境的一致性
- ✅ 符合真实网络架构

## 故障排除

如果遇到问题：
1. 确保服务器正在运行
2. 检查端口8080是否被占用
3. 重启Unity实例
4. 删除克隆实例重新创建
